## 🌟 **О проекте**

**Cpp Craft** — это мощный визуальный конструктор кода на C++. Забудьте о рутинном написании шаблонного кода! Теперь у проекта есть **графический интерфейс**, построенный на библиотеке **FLTK**.

Просто выбирайте нужные компоненты через удобное окно с панелями, и программа сама соберёт готовый `.cpp` файл.

> **Эволюция проекта:** из консольного меню → в полноценное десктопное приложение с GUI.

---

## 🖥️ **Графический интерфейс**

Приложение построено на библиотеке **FLTK** и включает:

| Элемент | Описание |
|---------|----------|
| **Главное окно** | 800×600, фиксированный размер, адаптивный интерфейс |
| **Панель выбора (слева)** | Список категорий: **Libraries, Variables, Cycles, Switch‑Case, If, Else If, Arrays (1D/2D), Dynamic Arrays, Functions, Vector, FStream, OOP** |
| **Панель настроек (справа)** | Контекстные поля для каждого типа (например, название переменной, тип, значение) |
| **Блок кода (в центре)** | Отображение сгенерированного кода с прокруткой |
| **Кнопки управления** | 💾 **Save** / ▶️ **Run** / 👁️ **Preview** / 🗑️ **Clear** |
| **Интерактивность** | Клик по элементу — он добавляется/удаляется из генерации |

## 🔧 **Сборка**

### Установка FLTK

**Ubuntu/Debian:**

sudo apt update
sudo apt install libfltk1.3-dev

Fedora:

sudo dnf install fltk-devel

Arch Linux:

sudo pacman -S fltk

macOS (Homebrew):

brew install fltk

Windows:
Скачайте сборку FLTK с fltk.org и установите вручную.
Сборка с CMake (рекомендуется)
git clone https://github.com/nikitu0008-collab/CppCraft.git
cd CppCraft
mkdir build && cd build
cmake ..
cmake --build .

Исполняемый файл cppcraft появится в папке build/.
Ручная компиляция

Linux/macOS:

g++ -std=c++17 -Iinclude ui/*.cpp src/*.cpp -lfltk -o cppcraft

Windows (MSVC):
cmd

cl /EHsc /std:c++17 /Iinclude ui\*.cpp src\*.cpp /Fe:cppcraft.exe

🎬 Как использовать

    Запустите приложение → откроется главное окно.

    В левой панели выберите категорию (например, Variables).

    В правой панели заполните параметры (тип, имя, значение).

    Нажмите Add — блок добавится в центральную область кода.

    Продолжайте добавлять нужные компоненты.

    Когда код готов, нажмите Save (💾) или Run (▶️) — сгенерированный .cpp файл появится в папке Generated/.
